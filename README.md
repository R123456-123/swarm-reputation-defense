# Transcript-Verified Reputation for AI Swarms

Built for Track 3 of the Swarm Alignment Hackathon (2026).

## Overview

This project demonstrates how machine-speed Sybil attacks can instantly compromise standard AI agent reputation systems, and proposes an external Gateway Reference Monitor as a fix.

## How to Run

1. Install requirements: `pip install -r requirements.txt`
2. Run the simulation (generates baseline and defense data): `python src/simulation.py`
3. Generate the visualization: `python src/graph.py`

_Note: All code was written entirely during the hackathon weekend._
